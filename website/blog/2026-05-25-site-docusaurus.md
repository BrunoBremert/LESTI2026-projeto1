O EventFlow ganhou um site em Docusaurus para apresentar a aplicacao,
documentar instalacao e reunir evidencias do fluxo de trabalho Git.

<!-- truncate -->

Esta etapa acrescenta uma camada publica ao projeto:

- homepage com proposta de valor;
- documentacao tecnica do produto;
- guia de instalacao;
- pagina dedicada ao uso de Git;
- demonstracao de recursos Markdown.

O proximo passo recomendado e criar uma branch `feature/site-docusaurus`, fazer
commits faseados e abrir uma pull request para integrar o site em `main`.
