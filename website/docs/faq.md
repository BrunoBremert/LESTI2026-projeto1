# FAQ

## Perguntas Frequentes

:::tip
Esta página reúne as principais dúvidas sobre a aplicação, o site Docusaurus e o uso do Git no projeto.
:::

---

## Como executar o site Docusaurus?

Entre na pasta `website` e execute:

```bash
npm install
npm start
```

---

## Como executar o programa?

Na raiz do projeto, execute:

```bash
python main.py
```

## Onde os dados da aplicação são guardados?

Os dados são guardados em ficheiros JSON dentro da pasta: 

```bash
data/
```
